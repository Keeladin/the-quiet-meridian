THE QUIET MERIDIAN — OPENING HIDDEN-OBJECT PREVIEW v3.1

This is one playable search for reviewing the new gameplay direction.
It is not the completed campaign conversion.

Extract the whole archive before playing. On Linux, double-click dispatch-search.x86_64
(or mark it executable if your archive tool does not preserve permissions).
On Windows, run dispatch-search.exe. Keep dispatch-search.pck beside the executable.
No editor, account, network, API key or paid generation is needed to play.

Starts fullscreen. F11 toggles fullscreen; Escape returns to a window.
Click the objects named in the list. Found names cross off. Find all seventeen clues
to recover the dispatch receipt. There is no penalty for a wrong click.
Scroll or use + / - to zoom. Right-drag to pan; Fit shows the whole picture.
Hint highlights one remaining object and recharges in 20 seconds.
Click the picture then use arrow keys to move a search cursor; Enter selects.
Hold Shift with an arrow for a larger movement. Tab reaches the controls.
Sound toggles every audio layer. Music toggles only the existing background score,
so you can listen to the selected room atmosphere on its own. Exit closes the game.

Progress saves after each find to a separate hidden-object-preview folder.
This audio revision resumes the v2 search. Use Start again to hear a fresh completion.
Your current adventure installation and saves are unaffected. Start again
resets only this preview after confirmation.

Original search art: OpenAI built-in image generation, 14 November 2026.
Thirteen Gamemaster Audio recordings selected by Jaco now supply the room
atmosphere, discoveries, hints, controls and completion sounds. The existing
project score remains, at a quieter level. See LICENSES.md,
SCORE_DESIGN.md, assets/fonts/LICENSE.txt and GODOT_NOTICES.txt for notices.

Review focus: listen to the opening room, discovery sounds and completion.
The prepared mix awaits your listening feedback. This revision uses denser overlap, symbols and familiar synonyms.
An object, an illustrated symbol or a shape in the scenery can fit a clue.
Some clues have more than one valid visible match; finding any one counts once.
Later searches still need authoring, story integration and independent playtests.

The source archive excludes the purchased reusable sound files. Licensed owners
can restore them using docs/RESTORE_LICENSED_AUDIO.md. Playable packages contain
the sounds and require no restoration.

Audio balance update: quieter ocean and more audible rain. Existing preview
progress is preserved. No restart of the search is needed to hear this change.
