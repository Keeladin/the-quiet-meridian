These development captures are excluded from the running game by `.gdignore`.
Original PCM, transcript, filtered events and final usage receipts are preserved.

are retained as failure evidence, not offered as voice performances.

authorization headers or provider error bodies are retained. See
`docs/VOICE_SAMPLE_REVIEW.md` and `docs/VOICE_PRODUCTION.md` for outcomes and terms.
