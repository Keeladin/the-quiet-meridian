# Mystery game project

Read DEVELOPMENT_BRIEF.md and docs/PRODUCTION_PLAN.md before development.
The requested finished product is a 6–10 hour original 2D mystery adventure.
The current scene is a setup probe, not a prototype or completed gameplay.

Work inside this repository. Do not modify Atlas, GCC, other projects,
system packages, user-wide configuration, or any server services.
Use Godot 4.7.2, GDScript, and the Compatibility renderer unless evidence
supports an intentional change. Keep Windows and Linux x86_64 exports working.
Run tools/game.sh verify after meaningful engine or resource changes.
Add meaningful puzzle/state/save tests as those systems are implemented.
Do not present successful setup checks as a full playthrough or a release.

Use available built-in image generation for original raster artwork; consult
docs/ARTWORK_WORKFLOW.md. Keep final assets, prompts, provenance and licensing
records in the repository. Never leave referenced assets only in tool caches.
Keep narrative, location and puzzle data separate from engine systems.
Maintain the dependency map and update the production plan after each milestone.
Create local Git checkpoints; no publishing, remote uploads or paid API setup
is implied by this brief. Do not store credentials in the repository.

## Sound selection and listening review

The owner has delegated routine sound selection and mixing to Codex; do not
require approval of each recording. Select suitable sounds from the purchased
library using the scene/action, source descriptions and audio analysis. Record
exact files, provenance, preparation and event mapping in
`docs/audio-selection/requests.json` and related manifests. Keep the thirteen
opening recordings already selected by Jaco unless a requested revision needs
an explicit change. Owner preferences and overrides take priority.

The current session does not provide reliable subjective hearing. Do not claim
to have listened when only technical checks were performed. Use occasional
whole-room gameplay feedback to refine atmosphere and balance, rather than
asking the owner to audition every sound. There is no fixed creative cap on
sound count. Preserve the original library and package only sounds in use.
